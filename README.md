# NMD

A modern one-page website built with Next.js and Tailwind CSS.

## Features
- Fast and performant
- Stylish design with Tailwind CSS
- Powered by Next.js App Router

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Run the development server:
   ```sh
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Customization
Edit `app/page.tsx` to update the content and layout.
